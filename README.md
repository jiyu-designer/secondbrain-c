# 점심 메뉴 추천 앱

오늘 점심 뭐 먹을지 고민될 때 사용하는 간단한 웹 앱입니다!

## 주요 기능

- **랜덤 메뉴 추천**: 버튼 클릭 한 번으로 오늘의 점심 메뉴를 추천받을 수 있습니다
- **카테고리 필터**: 한식, 중식, 일식, 양식, 분식, 아시안 등 원하는 카테고리별로 필터링 가능
- **추천 기록**: 최근 추천받은 메뉴 10개를 기록하여 확인 가능
- **로컬 저장**: 브라우저의 로컬 스토리지를 활용하여 기록 유지
- **반응형 디자인**: 모바일, 태블릿, PC 모든 기기에서 사용 가능

## 사용 방법

1. 웹 브라우저로 `index.html` 파일을 엽니다
2. 원하는 카테고리를 선택합니다 (선택하지 않으면 전체 메뉴에서 추천)
3. "메뉴 추천받기" 버튼을 클릭합니다
4. 추천된 메뉴를 확인합니다!

### 키보드 단축키

- **Enter**: 메뉴 추천받기

## 기술 스택

- **HTML5**: 웹 페이지 구조
- **CSS3**: 스타일링 및 애니메이션
- **JavaScript (Vanilla)**: 메뉴 추천 로직 및 상태 관리
- **LocalStorage**: 추천 기록 저장

## 메뉴 목록

현재 50개 이상의 다양한 메뉴가 등록되어 있습니다:

- **한식**: 김치찌개, 된장찌개, 불고기, 삼겹살, 비빔밥 등
- **중식**: 짜장면, 짬뽕, 탕수육, 마라탕, 깐풍기 등
- **일식**: 초밥, 라멘, 돈까스, 우동, 회덮밥 등
- **양식**: 스테이크, 파스타, 피자, 햄버거, 리조또 등
- **분식**: 떡볶이, 순대, 튀김, 김밥, 라면 등
- **아시안**: 쌀국수, 팟타이, 분짜, 월남쌈, 똠얌꿍 등

## 커스터마이징

`app.js` 파일의 `menuData` 배열을 수정하여 원하는 메뉴를 추가하거나 삭제할 수 있습니다:

```javascript
const menuData = [
    {
        name: '메뉴이름',
        category: '카테고리',
        emoji: '이모지',
        description: '설명'
    },
    // ... 더 많은 메뉴
];
```
